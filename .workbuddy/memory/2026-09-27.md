## 祝福修复
- **眷顾全程未生效根因**：BlessingManager.GetCurrentPriceMultiplier()（眷顾/友情折扣/辩证主义价格修正）从未被调用。已把该乘数接入 ShopManager 三个 GetCurrentXxxPriceMultiplier()；另发现 BlessingData.CalculatePrice 收了 priceMultiplier 参数但从未使用，已修复为末尾应用乘数。
- **财星**：GameManager 原来每回合都用 wealthStarCount（全局生效）。改为 wealthStarPendingCharges 机制：购买时 +1，下次结算 ConsumeWealthStarCharges() 消费，用后失效。
- **慈爱星**：原实现当回合无绿色数字时不消耗、静默延后；改为严格下一回合一次性消费（lastApplied 无论是否找到绿卡都更新），多次购买按差额叠加。
- **祝福双重扣费**：ShopManager.TryBuyBlessing 先扣 item.price，BlessingManager.TryBuyBlessing 内又扣一次。已移除 ShopManager 的扣费，统一由 BlessingManager 计价扣费。
- **大七星减星错位**：DecreaseStarCountVariable 按代码旧 blessingId（49-54）匹配，资产实际 ID 是 51-58，全部错位；改为按 blessingType 匹配。

## 数字卡价格公式（NumberCardData.cs）
按用户提供的规范重写为浮点：骰子期望 (x+1)/2.0（原为整数除法）、{y}=y+5、{x}*{y}=Σ(x+i)(y+i)/9、8 种指数组合全部按 Σ/均值公式（原来 long 累加，20^20 会溢出）；X*rate 用 AwayFromZero 取整；黄金数修正与四步舍入保持。
