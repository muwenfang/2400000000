# 2026-10-31

## “继续游戏”按钮自动显隐
- UIManager 新增 Inspector 字段 `continueGameButton` + `UpdateContinueGameButton()`（按 `GameManager.HasContinueSave()` SetActive）。
- `GameManager.ChangeState` 的 MainMenu 分支调用它；Start() → ChangeState(MainMenu) 覆盖启动场景，返回主菜单/胜负清档后回菜单也自动刷新。
- 开新游戏（InitializeGame）先 ClearSave，之后回主菜单按钮自动隐藏。
- hc_check 新增 2 条守卫，回归 252 项全过。用户需在 Inspector 把主菜单按钮拖入 UIManager.continueGameButton。

## 存档生命周期收紧：只有开新游戏作废存档（用户约定）
- `WinGame(bool isWin)` 移除 `RunSaveManager.ClearSave()`：胜负结束后存档原样保留，继续游戏可退回胜负前状态。
- `EnterEndlessMode` 移除 ClearSave：无尽延续同一局（点数/卡牌/祝福全保留，仅 round=61），清档只会制造崩溃丢档窗口。
- `ReturnStartMenu`：补算触发胜负（GameOver/GameLose）→ 不写档；仅"公式未填满无法补算"时按未结算 SaveRun（修复此前该路径完全漏存的缺口）。
- `OnApplicationQuit` 同理：SaveRun 的 default 分支对 MainMenu/GameOver/GameLose 本来就不写档。
- 清档调用点剩两个：`InitializeGame` / `InitializeGame_invol`。
- 相关注释/日志同步更新；hc_check 守卫改为「胜负不清档」「无尽不清档」，回归 252 项全过。
