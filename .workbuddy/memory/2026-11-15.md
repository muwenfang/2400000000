## 排查「数字卡/祝福不显示、只有公式卡显示」
- 结论（已用资产 YAML 证实）：`Assets/prefabs/cardUI/NumberCardColletction.prefab`（数字卡条目）与
  `BlessCollection.prefab`（祝福条目）**根节点 RectTransform 存的是 m_LocalScale = (0,0,0) / m_SizeDelta = (0,0)**
  （当初当模板用过）；而 `FormulaCollection.prefab` 根节点是 (1,1,1)。图鉴面板实例化条目后没复位缩放，
  整条条目被缩成 0 → 表现为"该区域什么都没有"。
- 卡牌库（ShowMyNumberCard.GenerateNumberCards / ShowMyBlessings.CreateBlessingCard）里那两句
  `go.transform.localScale = Vector3.one` 就是为同一批"0 缩放模板预制体"兜底的，不是冗余代码。
- 卡牌预制体本身（Normal/Add/Multiple/Power/BlessInShop）根节点同样是 0 缩放 + 0 尺寸，真正的图形在子物体上；
  它们靠 GridLayoutGroup 撑尺寸。图鉴挂点没有布局组，所以补齐：锚点/轴心居中 + 0 尺寸时用挂点尺寸兜底。
- 修复：`CardCodexPanelUI.PrepareEntryTransform`（条目 SetActive + scale=1 + rotation=identity）、
  `PrepareCardTransform(card, slot)`（卡面同上 + 居中 + 尺寸兜底）。
- Editor.log 里 577 条 `[图鉴] 条目预制体未配置` 是单容器旧版（三个预制体还没拖）留下的历史日志，不是本次原因。
- 附带发现：这两个条目预制体根上还挂着 Canvas(Overlay) + CanvasScaler + GraphicRaycaster（复制面板留下的），
  144 条条目 = 144 个嵌套 Canvas + Raycaster，建议在预制体里删掉这三件。
- 离线回归 308 项全通过（新增 3 项缩放/尺寸守卫）。
