# 2026-11-23

## 成就提示条改为「预制体 + 队列堆叠」（Steam 风格）

- 原 `AchievementToastUI` 是单条复用、串行播放，且场景 `achivementBar` 处于未激活，等于不显示。
- 拆成两个脚本（UI 仍全部由用户在 Inspector 搭，代码不生成界面）：
  - `Assets/scripts/UI/Achievement/AchievementToastUI.cs`：单条实例，挂预制体根节点。只改 `nameText` 文字（可选 `descText`），动画 = 弹入(fadeInDuration, popScale) → 停留(holdDuration) → 淡出(fadeOutDuration)，走 unscaledTime；播完回调管理器。预留序列化字段名与旧版一致（nameText/canvasGroup/fadeInDuration/holdDuration/fadeOutDuration/toastTextFormat），场景旧数据不丢。
  - `Assets/scripts/UI/Achievement/AchievementToastManager.cs`：订阅 `AchievementManager.AchievementUnlocked`，`toastPrefab` + `toastContainer`（Inspector 拖），队列按 `spawnInterval` 逐条弹，`maxVisible` 满员走背压等待（不截断成就）；容器有 LayoutGroup 交给布局组排，无则用 `BuildStackOffsets` 手工堆叠（`stackSpacing`/`stackUpward`/`fallbackItemHeight`）。
- 要点：`Instantiate(prefab, container, false)` + `SetAsLastSibling`；在重排前采集 `stackOrigin`；Play 内部先置 alpha=0 再 SetActive（防闪白框）；CanvasGroup 强制 `blocksRaycasts=false`（提示条不吃点击）。
- 兜底：`nameText` 未拖时按节点名含 name/名字 查找，只有一个 Text 时直接用；多个且认不出则警告。
- 校验：hc_check 新增 `TestAchievementToast` 16 项（堆叠偏移纯计算 + 源码挂点守卫），总 409 项全通过。
